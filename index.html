欢迎使用 MYUTAU 音源制作工具！
支持制作真人音源和无生物音源，所有处理均在您的浏览器本地完成，
不会上传任何文件到网络服务器。请准备好您的素材后开始制作！
🎤 真人音源制作
🔔 无生物音源
🎚️ 参数调节
📦 一键导出ZIP
💡 小提示：真人音源需要预先录制完整音表的wav文件；无生物音源只需一段原始素材，工具会自动拆分生成多音阶采样。
支持语言：日语、汉语、英语、韩语、西班牙语、法语、德语、俄语
支持格式：CV / VCV / CVVC

步骤1：选择音源类型

请选择您要制作的音源类型。不同类型的制作流程和采样要求不同。
🎤

真人音源

✓ 适合人声演唱音源
✓ 需要预先录制完整音表
✓ 人声专用切割算法
✓ 支持性转、颤音调节
✓ 自动生成oto.ini

🔔

无生物音源

✓ 适合器物声、敲击声、环境音
✓ 只需一段原始音频素材
✓ AI自动拆分生成多音阶采样
✓ 支持音色、颤音调节
✓ 自动生成oto.ini

步骤2：基础设置

请选择音源的语言、音阶数量和音源格式。工具会根据这些参数生成对应的音素表。

基本参数

CV最简单入门；VCV最自然但采样量大；CVVC介于两者之间
基准音阶：C4 | 音阶数：5 | 范围：C4 ~ G4

音素表预览

点击下方按钮生成音素表

步骤3：上传录音采样

请将所有录音wav文件打包成zip上传。
文件名必须与音素表完全一致（例如：あ.wav、か.wav）。
工具会校验所有必需的采样文件是否齐全，齐全后才可进入下一步。

📁

将采样zip拖到这里，或点击下方按钮选择文件

仅接受 .zip 格式 | wav文件名需对应音素名

上传校验结果

步骤3：上传原始素材

请上传一段完整的原始音频（wav格式），例如敲击声、器物声、环境音等。
工具会自动处理这段素材，裁剪静音、消除爆音、归一化音量，
然后拆分生成对应音阶和音素的完整采样包。

🎵

将原始wav拖到这里，或点击下方按钮选择文件

建议时长：5~30秒 | 越清晰效果越好

步骤4：全局音频参数调节

调节全局音频参数，试听满意后再进入下一步。所有修改实时生效。

🎚️ 音频参数

0 负值=更男性 / 正值=更女性
10 0=无颤音，越大颤音越强
50 数值越大颤音越快

步骤5：OTO生成与微调

工具已自动生成oto.ini参数。点击音素名可播放试听，也可以手动微调各参数。
Offset=起始偏移 | Preutter=先行发音 | Overlap=重叠 | Velocity=速度
